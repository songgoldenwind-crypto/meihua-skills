# 梅花易数 Skill

这是一个可独立安装的梅花易数 Agent Skill。它先用可复核的输入起卦，由程序计算本卦、互卦、变卦、动爻和体用，再按所问事项解读。**起卦方法**决定盘怎么来，**占问类型**决定这张盘回答什么；同一问题通常只选一种起法，不因结果不合意而换方法重起。规则入口见 [SKILL.md](SKILL.md)。

## 能占什么

默认按梅花主法的分类占规则处理下列事项。提问时说清具体对象、所问阶段和期限；Skill 会先判断盘面最多支持到哪一阶段，再讨论趋势与时间，不把“有消息”写成“已经录用”或“已经成交”。完整规则见 [分类占](references/05-topic-reading.md)。

| 占问类型 | 可以怎样问 | 主要看什么 |
| --- | --- | --- |
| 天时 | 某地某一时段的天气变化象意 | 本互变、季节与晴雨风的变化；不能代替天气预报。 |
| 人事 | 一件具体事情能否推进 | 主体与事项的体用关系，以及办理过程。 |
| 家宅 | 家庭运行或居住关系怎样 | 人、费用、维护与家庭协调。 |
| 屋舍 | 某处房屋或场地是否适合使用 | 使用者与场地的关系、取得和维护条件。 |
| 婚姻与关系 | 关系能否从接触推进到确认 | 双向互动、条件是否一致和实际行动。 |
| 生产与新增成果 | 项目、作品或产品能否交付 | 准备、产出和上线过程；不用于推断孕产医疗结果。 |
| 饮食 | 邀约或餐食能否落实、有哪些线索 | 是否成席、谁准备，以及饮食类别与状态。 |
| 求谋 | 一个计划能否从想法走向执行 | 资源、协作、行动和完成条件。 |
| 求名、考试与求职 | 招聘、考试或资格进展如何 | 资格 → 联系/准备 → 面试/考试 → 决定 → 到岗/录取；薪资等条件另核事实。 |
| 求财 | 一笔钱能否取得、何时到账 | 来源 → 履约 → 到账 → 留存；不把财象当成实际到账。 |
| 交易 | 买卖或合作能否谈成 | 谈判、签约、交割和售后。 |
| 出行 | 一次行程能否按计划推进 | 准备、启程、途中、到达与返程。 |
| 行人与来人 | 等待的人或消息是否会到 | 有意、动身、接近、到达；消息不等于人已到。 |
| 谒见与会面 | 能否约到、见到某人 | 预约、引荐、会面和反馈。 |
| 失物 | 丢失物品的查找线索 | 可控范围、可能方位、发现和取回；方位只是搜索优先级。 |
| 疾病与健康 | 传统卦象怎样描述支持或阻滞 | 只作象意讨论，不诊断、不决定用药或治疗。 |
| 官讼与争议 | 争议流程可能怎样推进 | 事实证据、沟通、程序、解决和执行；不代替法律意见。 |
| 坟墓、土地与长期安置 | 场地或安置方案是否适配 | 地形、手续、费用与维护；权属和安全须实地核实。 |

还有三种专项用法：[观物](references/11-object-reading.md)可以按卦象讨论物品的形态、材质、用途、数量级或器物能否制成；[屋宅与店铺](references/13-house-environment.md)可把选址、合同、装修、开业和经营分阶段看；[应期](references/04-timing.md)只对已经获得主链支持的阶段给时间线索。它们仍使用已固定的一张盘，不是额外起卦方式。

## 起卦方法

**上卦、下卦**按乾一、兑二、离三、震四、巽五、坎六、艮七、坤八取数，除八取余，余零取坤；**动爻**除六取余，余零取第六爻。下表的“数”均须在看到卦盘前确定。完整输入条件与算式见[起卦公式](references/01-casting-methods.md)。

| 起法 | 所需原始输入 | 上卦／下卦／动爻的取法 | 排盘入口 |
| --- | --- | --- | --- |
| 年月日时 | 起念或事件的当地时间、时区；或已核实的农历年支、月、日、时支 | 年支数＋农历月数＋日数取上；再加时支数取下，同一总数取动爻。默认不把分钟、秒数入卦。 | 公历用 `time`；已核农历用 `lunar-time` |
| 两数 | 事前给定的两个正整数 | 第一数取上，第二数取下，两数之和取动爻。 | `numbers` |
| 三数 | 事前给定的三个正整数 | 第一数取上，第二数取下，第三数取动爻。若选总和取动爻，须事前声明。 | `numbers` |
| 物数 | 真实可数的物品数量、当时时支 | 物数取上，时支数取下，两数之和取动爻。 | `numbers` |
| 声数 | 当时一组清楚可数的声音次数、时支 | 声数取上，声数＋时支数取下，同一总数取动爻。持续背景噪声不强行计数。 | `sound` |
| 字数、句数 | 固定原文，明确统计字数的口径 | 一段文字：偶数均分，奇数上段少一字；上下段字数取卦，总字数取动爻。两句文字可事前约定前后句字数分别取卦，两句总字数取动爻。 | `numbers` |
| 单字笔画 | 原字字形、左右或上下两组经核实的笔画数 | 两组笔画分别取上、下卦，总笔画取动爻。繁简、异体及手写字形按实际原字核定。 | `strokes` |
| 丈尺或尺寸 | 真实长度与事前选定的单位；尺寸法还需时支 | 丈尺法：丈取上、尺取下，丈尺和取动爻；尺寸法：尺取上、寸取下，尺寸和加时支数取动爻。 | `numbers` |
| 人物、动物、器物或外应 | 与起念同步的真实异常动作或来物、实际来方、发生时间 | 先按最突出的真实特征定物象上卦，按实际来方定下卦；物象卦数＋方位卦数＋时支数取动爻。先冻结取象依据，再运行程序。 | `external-omen` |

下面是**事前明确选择才使用**的数字变体，不替代默认年月日时法，也不能算出多张盘后挑选结果：

| 可选起法 | 上卦／下卦／动爻的取法 | 特别条件 |
| --- | --- | --- |
| 抓米两次 | 第二次米粒数取上、第一次取下，两次数加时支数取动爻。 | 两次真实计数与时支均须已知；不同于普通两数法。 |
| 钟点 | 当地表盘小时整数取上、分钟整数取下，两数之和取动爻。 | 12 小时制或 24 小时制须事前确定；分钟在此法入卦。 |
| 钟点拆位 | 小时各位数字之和取上、分钟各位数字之和取下，两组之和取动爻。 | 与直接用小时、分钟整数是两种不同起法。 |
| 电话末四位 | 前两位数字之和取上、后两位数字之和取下，四位数字之和取动爻。 | 保留原始四位和前导零；分组和为零时现有入口不能排盘，不事后改数。 |
| 姓名笔画 | 经核实的姓氏笔画取上、名字总笔画取下，合数取动爻。 | 先核实具体字形与笔画，不凭模型记忆猜数。 |

这些变体在固定原始输入和算式后，按[起卦公式](references/01-casting-methods.md#预先锁定的数字变体)换算，再交给 `numbers` 排盘。另有声调配数口径，但必须事前提供已确认的音系、声调数表、文字分组及动爻算法；本仓库不会从现代普通话自动推断古音或补造数表。已知上卦、下卦和动爻时，`manual` 仅用于**复核已有卦盘**，不是起卦法。下文的策轨、太极点、飞宫和数码结构等是独立分析层或辅助计算，不自动构成另一张梅花卦；其中电话末四位**起卦**与手机号**数码结构分析**也须分清。

## 怎么用

1. **说清问题。** 例如“这家公司的面试是否会进入下一轮”，给出对象和希望判断的期限；采用时间或外应起卦时，再给出发生时间和所在地/时区。多个公司或事项应分别说明，不能用一张盘直接指定哪家公司录用。
2. **选一种起法。** 已有真实时间、数字、声音、文字或突发外应时，按上表选对应入口。用户明确指定方法就按该法；信息不足时先补齐，不用模型猜数字、笔画或方位。
3. **让 Agent 排盘并解读。** 安装后可说：“请用 `meihua-divination`，以我提供的时间起卦，先报本互变与体用，再判断这次面试能否进入下一轮。”Agent 应调用本仓库脚本排盘，再按 [判断顺序](SKILL.md#判断顺序) 解释。

如果时间卦已经排出，同场出现的声音或物象通常只作[外应旁证](references/03-external-omens.md)，不再拿它重起一盘。原卦完成后出现真实新事件，并且明确要求复占时，才可另成新局；两局不能拼接有利片段。同一个问题没有新阶段或新事件时，以现实进展核对原卦。

### 可以直接这样向 Agent 提问

> 请用梅花易数，以 2026 年 9 月 15 日 11:00、中国上海时间起卦，看这次面试能否进入下一轮；先报排盘依据，再判断联系、下一轮和录用分别有没有支持。

> 我现在报 23、41 两个数，问这笔交易本周能否签约。请按两数法起卦，说明谈判、签约和到账不能混为一个结果。

> 我起念时听到三声清楚的敲门声，当时是申时。请按声数法起卦，先记录原始声音次数，不要再拿声音另作一张外应卦。

> 我刚看到一辆车从正南方突然启动，事件发生在申时。请先判断这是否足以构成外应，再写明物象卦、方位卦及各自依据，最后调用排盘程序。

这些是**提问格式示例**，不是对示例事件的真实占断。时间、时区、数字、方向和事件必须按实际情况替换。

## 安装与排盘命令

支持从 GitHub 仓库安装 Skill 的 Agent，可直接选择本仓库根目录。手动安装到 Codex：

```bash
git clone https://github.com/songgoldenwind-crypto/meihua-skills.git
mkdir -p "$HOME/.codex/skills"
cp -R meihua-skills "$HOME/.codex/skills/meihua-divination"
```

使用其他 Agent 时，把仓库复制到该 Agent 的 Skill 目录，让它读取根目录的 `SKILL.md`。首次使用建议重新开启 Agent 会话。常用排盘脚本需要 Python 3.10 或更新版本；内置依赖按许可证附带，无需联网安装。从仓库根目录运行：

```bash
# 公历时间、两数、已核笔画、声数
python3 scripts/meihua-engine/paipan.py time --datetime 2026-09-15T11:00 --timezone Asia/Shanghai
python3 scripts/meihua-engine/paipan.py numbers --upper-number 23 --lower-number 41
python3 scripts/meihua-engine/paipan.py strokes --upper-number 3 --lower-number 5 --moving-number 8
python3 scripts/meihua-engine/paipan.py sound --count 3 --hour-branch 申

# 外应：下面的物象、来方和时间须先据真实事件固定
python3 scripts/meihua-engine/paipan.py external-omen \
  --object-trigram 震 --object-evidence "车辆突然启动，以动态取震" \
  --direction-trigram 离 --direction-evidence "车辆从正南方来" \
  --hour-branch 申 --context-datetime 2026-09-15T15:00 --timezone Asia/Shanghai

# 对已经知道的上下卦和动爻做盘面复核
python3 scripts/meihua-engine/paipan.py manual --upper 震 --lower 离 --moving-line 3
```

更多参数及输出字段见 [排盘脚本说明](scripts/meihua-engine/README.md)。这些命令输出 JSON 盘面；事项判断由 Agent 依 `SKILL.md` 和对应参考规则完成，脚本本身不会自动预测结果。

## 可选方法怎么用

默认盘按梅花主链解读。以下是**明确指定时才用**的独立方法；先固定起法和底层盘，再读取对应规则，不把不同方法的公式、旺衰与应期拼成同一套：

| 方法 | 适用条件 | 本仓库提供什么 |
| --- | --- | --- |
| [策轨与古音组合](references/18-cegui-phonetic.md) | 明确指定；古音法还须先核古反切和声卦、音卦 | 对已定卦爻复算策轨身数、乘加，或复算已定声/音卦的挂一定位；不自动猜古音。 |
| [太极点卦组法](references/19-taiji-overlay.md) | 明确指定，先按占问固定太极点 | 列卦组、月令、纳支、空亡等证据和条件应期；不自动判从格或唯一日期。 |
| [飞宫日月法](references/20-flying-overlay.md) | 排盘前选定相应起数口径 | 对固定卦盘输出飞宫与日月标签；不事后改成另一种钟点或数字盘。 |
| [数码结构法](references/21-number-profile.md) | 明确研究手机号或末四位数位 | 列数字结构与流年候选；不把候选包装成唯一应验年份。 |

实际命令见 [方法辅助器说明](scripts/source-variants/README.md)，适用条件和未自动执行的步骤见 [方法分流](references/15-method-routing.md)。本公开仓库只写方法，不公开资料的书名、作者、版本、页码或原件。

## 能力边界

- 这个仓库不含独立的拆字测字 Skill，也不含六爻纳甲 Skill。已核实笔画的梅花字数卦可以做；铜钱六爻和“梅起爻断”需要相应的其他 Skill。
- 应期须先确定所问的现实阶段和时间尺度。卦纳地支、动爻数或节令只能提供候选线索，不能单独推出某日必然录用、成交或到账。
- 术数解读表达传统体系内的象意与趋势，不保证现实结果。天气、医疗、法律、房屋安全和投资等现实决定应依据可核实的信息与专业意见。
