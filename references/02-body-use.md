# 体用、本互变与生克

## 定体用

一个动爻时，动爻所在的经卦为**用**，未动的经卦为**体**。体是所问主体、承受方或自身条件；用是所问之事、对方、环境或施加作用的一方。体用是本次问题中的关系，不把体永久等同于“我”，也不把用永久等同于“坏事”。

若输入本身没有动爻，不能补造体用。多个动爻的铜钱卦不强行改成梅花单动爻结构。

## 五行关系

生序为木生火、火生土、土生金、金生水、水生木；克序为木克土、土克水、水克火、火克金、金克木。

| 关系 | 基本含义 | 必须再查 |
|---|---|---|
| 用生体 | 外部条件、对方或事项支持主体 | 支持能否落到所问阶段，体能否承受 |
| 体克用 | 主体能掌控或取得事项 | 体是否有力，掌控成本是否过高 |
| 体用比和 | 同类、协同或阻力较少 | 是否只是停留在同类状态，后续有无落实 |
| 体生用 | 主体投入、付出或被事项消耗 | 投入能否换来后续回生，不直接等于失败 |
| 用克体 | 外部压力、事项压制主体 | 互卦或变卦是否通关、转生或止克 |

生克表示关系方向，不是机械分数。卦气、时令、对象的真实强弱和所问目标会改变关系能否实现。例如体克用对“取得对象”可有利，对“休息减负”则可能表示仍需耗力控制。

## 本卦、互卦、变卦

- **本卦：** 起点、当前结构和事情为何发生。
- **互卦：** 二至五爻构成的中间过程。下互取二三四爻，上互取三四五爻。体在上则上互为体互、下互为用互；体在下则下互为体互、上互为用互。体互说明主体中段条件，用互说明事项中段条件，不另立无关故事。
- **变卦：** 动爻改变后的趋向或结果条件。它表示结构怎样转化，不保证现实必然完成。

先写一条连续链：本卦中的体用关系如何进入互卦的中间条件，又怎样在变卦中得到支持、耗损、受克、比和或停止。若互卦和变卦相反，说明阶段变化和触发条件，不用一句“吉凶参半”带过。

程序已经输出 `body_position`、`use_position`、`body_mutual` 和 `use_mutual`，不得凭卦名重新分配。卦气旺衰、真假生克、动静向背和十应的完整次序见 [06-advanced-interpretation.md](06-advanced-interpretation.md)。

## 卦象取用

卦象只在体用主链成立后用于限定现实含义。优先级如下：

1. 用户已说明的对象、阶段和期限。
2. 体用五行关系及本互变顺序。
3. 八卦的物类、人物、方位、动作和爻位。
4. 同步外应。

同一卦可对应很多物类。每次只选能解释主链的一至两个象；不能把乾同时扩成领导、父亲、政府、圆物和西北方，再从中任意挑应验项。

## 结论层级

先把事项拆成现实阶段，例如求职为“机会出现 → 联系 → 面试 → 条件确认 → 入职”，关系为“接触 → 互动 → 确认 → 稳定”。体用关系只走到某一层时，就停在那一层；用生体不直接等于最终录用、到账、结婚或痊愈。
