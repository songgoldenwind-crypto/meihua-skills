# 心易、先后天与解释优先级

本章按先天数卦、后天端法、体用、内外、动静、向背和现场证据确定解释顺序，防止公式正确而解释失控。

## 心易不是任意联想

同一经卦可对应多种人物、器物和动作。所谓“变通”是在已经固定的问题、盘面和现场中选择最贴近的一项，不是看到结果后重新挑起法或穷举所有类象。每条解释都要能回答：

1. 它来自本卦、体互、用互、变卦还是现场外应。
2. 它作用于现实流程的哪一环。
3. 为什么此处取这个象，而不取同卦的其他象。
4. 哪个现实条件能够验证或推翻它。

邻夜借物例中，乾巽既可像斧也可像锄；冬夜需要劈柴的现实用途排除了锄。此为“数先给范围，理再做约束”，不能倒过来先猜物品再拼象。

## 先天数卦与后天端法

| 项目 | 先天数卦 | 后天端法 |
| --- | --- | --- |
| 输入次序 | 先得数，再由数成卦 | 先见人物、物象、动作或方位，再定卦 |
| 常见入口 | 年月日时、数字、物数、声数、字数、笔画、尺寸 | 人物身份、身体动作、所持物、服色、动物异动、来方 |
| 动爻 | 依所选数法除六 | 物卦数、方位卦数与时支数合计除六 |
| 主要解释 | 体用、生克、本互变、卦气 | 体用、生克、本互变，并重视已冻结的现场物理情境 |
| 易辞 | 不必强用，必要时作辅助 | 可兼看已核的卦辞、动爻爻辞 |
| 禁止 | 用现场物象回改已经成卦的数字 | 见到盘面后更换人物卦、物卦或方位卦 |

本项目统一用先天八卦数 `乾1、兑2、离3、震4、巽5、坎6、艮7、坤8`。九宫数法不进入默认起卦。用户明确采用其他数值口径时，把其数值当作已经确认的输入交给 `manual` 或 `numbers`，不可静默替换默认公式。

其他周期数、声音数或观物系统也可能使用“体用”“先天”等术语，但它们的计算对象不同，不等于本 Skill 的单动爻体用法。不能把同名词直接换成梅花排盘公式。

按时方另取的选时神煞不进入本法。空亡、入墓、飞宫与日月标签若被用户明确指定，只能在各自的可选方法内讨论，不能塞进默认梅花体用主链。这里是方法边界，不对这些方法本身作有效性裁决。

## 卦辞、爻辞怎样参与

后天端法可以用卦辞和动爻爻辞限制情境，但必须满足三项：

- 确认引用的是本卦和实际动爻，不把变卦同位爻当成本爻。
- 若需逐字引用卦辞爻辞，只从用户提供或已核实的文本读取；不能凭模型记忆编造原文。
- 易辞先转成动作、条件或阶段，再与体用主链比较；不能只因一个“吉”“凶”字覆盖完整结构。

易辞与体用一致时，可提高结构解释的置信度；不一致时，先检查起法、动爻和文本版本，再判断它们是否分别指向不同阶段。仍冲突就保留冲突，不用所谓“变通”删掉反证。先天数卦没有可靠易辞文本时，仅按体用、本互变和卦气断，不影响排盘完整性。

## 一体百用与内外卦

体只有一个，表示本次所问的承受方或主体。用不只本卦另一经卦：本卦之用、体互、用互、变卦，以及真实天时、地理、人事与外物，都是不同层级的“用”。因此：

1. 本卦体用决定当前直接关系。
2. 体互、用互决定中段主体与事项条件。
3. 变卦决定末段结构。
4. 三要十应属于外层验证，必须再换算成与体的生克比和。

外应不能脱离内卦单独计吉凶。例如金银通常被视为好物，但震巽木为体时，真实锋利金器可能克体；棺木通常被视为凶物，离火为体时，木象反可能生体。这里说的是传统体系内部的关系转换，不把现实器物本身断成祸福。

## 解释证据优先级

出现多种信号时按下列次序裁决：

1. **输入事实与起法审计：** 用户给出的时间、数字、方位、动作是否准确，公式是否唯一。
2. **本卦直接关系：** 体用生克、比和及体是否承受得住。
3. **过程结构：** 体互、用互、变卦形成的连续阶段。
4. **旺衰与党多：** 只调整既有作用强度。
5. **与题直接相关的易辞或重卦语义：** 只限制相应阶段。
6. **真实同步外应：** 以真实作用、近而相关、动而有变者优先。
7. **类象、形色、谐音和歌诀：** 只用于具体化，不可反客为主。

同一来源不能重复计权。例如笑声既归兑象又归人事应时，只算一次；梅花体用和由同一本卦转出的六爻也不是两个独立起卦。

## 冲突裁决

- **卦吉、外应凶：** 先判断外应是否真实、同步、相关；成立则降低吉的程度或指出推进中的风险，不抹掉外应。
- **卦凶、外应吉：** 吉应只能说明存在缓解、协助或转机，不能把主链直接翻成大吉。
- **本卦与变卦相反：** 写成“先怎样、后怎样”，并给出使结构转化的条件。
- **体互与用互相反：** 主体准备与事项进程不同步，指出缺口落在哪一方。
- **卦名与生克相反：** 卦名只作语义限制，主链以可复核的体用结构为先。
- **古诀与现实流程相反：** 现实流程限定时间单位和可到达阶段，古诀不得越过必要步骤。

## 动静、向背与静占

“不动不占，不因事不占”用于选择有效触发。群动环境中只取最靠近求测人、最先引起注意、与问题最直接或动作最清楚的一项。主动来到面前的生体之象表示支持接近；背离而去表示作用减弱或已过。克体之象同理区分压力将至还是正在离开。

静室中确无特殊所见所闻时，外应留空，只按本互变、月令旺衰和问题流程判断。不得为了凑齐十应从普通背景中制造信号。

## 输出时的最小充分链

完整分析不等于罗列全部知识。最后应保留：一个直接判断、一条由本卦到互变的主链、一项最强现场验证、一个时间窗和一个反证。只有教学式、全盘式或用户明确要求逐项展开时，才展示其余层级。
