# 外应记录与取象

## 何时可以用

外应必须同时满足：发生在起念或起卦附近；确实被当事人观察到；相对日常背景具有突发、重复、异常或直接指向性；与所问能形成清楚的关系。普通背景、事后回忆和刻意寻找的符号不作为决定性外应。

记录四项原始信息：时间、位置或来方、实际发生了什么、为何当时引起注意。先记录再解释，不能先定结论后补选现象。

## 先分清是起卦还是旁证

- **外应起卦：** 当时的异常物象就是起卦入口。模型先验证现象并把物象定为上卦、来方定为下卦，冻结两项依据和时支，然后调用 `scripts/meihua-engine/paipan.py external-omen`。取余、动爻、本卦、互卦、变卦和体用全部以程序输出为准，之后才进入解读。
- **外应旁证：** 已经按时间、数字、声音等方法成卦。外应只能确认、削弱或限定既有主链，不能再次起卦，也不能用来改动原来的上下卦。
- **新事件复占：** 原卦结束后另有真实突发事件，用户又明确要求以它起卦。此时把它作为新的触发单独成局，不能同时把同一现象写成原卦旁证。先独立断新局，再比较两局支持到的现实阶段；有冲突就降低确定度，不以新局覆盖旧局。

外应起卦的模型输出先形成固定记录：`原始现象 → 采用特征 → 物象卦`、`真实来方 → 方位卦`、`事件实际时间 → 时支`。若用户只说“刚刚”且对话没有明显延迟，可使用系统接收时刻代记，并明确标成代记时刻；历史事件不得用当前系统时间代替。若物象多义、来方不明或现象只是普通背景，停止起卦并说明缺口，不让排盘结果倒逼取象。

## 取象次序

1. **真实作用优先。** 真实火、水、破损、阻路、来人或物体运动，比单纯红色、黑色、图案或谐音更直接。
2. **动作优先于静态。** 突然到来、掉落、鸣叫、争斗、开启、熄灭、破裂等通常比一直存在的摆设更能表示过程。
3. **近而相关优先。** 直接作用于求测人或所问对象的现象，比远处无关背景更有权重。
4. **一次只取主应。** 最突出的一个现象作主应，最多用一个独立现象复核；不要把环境里所有颜色、数字、声音都加入。

人物身份、动作和声音同时出现时，优先采用当时真正造成突发感的特征。比如“妻子突然笑”，若引起注意的是笑声，则以口、悦、发声取兑；妻子的身份不再重复取坤，坤只可在她确实来自西南方时作为方位卦。若两个特征同样突出且无法取舍，记录候选及疑义并停止排盘，不看结果择卦。

## 常见映射

- 天、圆、金属、首、马、刚健、西北可归乾。
- 泽、口舌、喜笑、缺口、少女、西可归兑。
- 火、光、电、文字、眼目、红紫、南可归离。
- 雷、足、车辆发动、惊动、长男、东可归震。
- 风、绳、木、气味、进入、长女、东南可归巽。
- 水、雨、沟渠、耳、险阻、中男、北可归坎。
- 山、门槛、手、狗、停止、少男、东北可归艮。
- 地、布帛、腹、牛、承载、母、西南可归坤。

映射必须说明“哪一条实际特征”被采用。一个对象同时像多卦时，用它在当时最突出的动作或方位限定；仍无法区分就保留疑义，不强配。

## 外应怎样进入判断

外应只做三件事：确认主链、指出转折、调整快慢或程度。把它放回体用：它生体、克体、帮助用、阻住用，还是显示事情在动、停、散、合。若外应与本互变明显相反，写成反证并降低确定度，不删除它来保住原结论。

进一步区分真实作用与形色类象、作用大小、来去向背及动静快慢；同一现象不能在方应、外应、人事应中重复计权。完整规则见 [06-advanced-interpretation.md](06-advanced-interpretation.md)。

外应不能确认疾病、死亡、犯罪、出轨、怀孕、胎儿性别或他人私密行为。听到一句话、看到车牌或颜色，也不能据此断出具体姓名、金额和日期。
