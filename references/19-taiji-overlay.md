# 太极点、卦组与条件应期

仅在用户明确选择这一方法时使用。先按问题固定太极点的位置与理由，记录“所问 → 太极点所在经卦 → 取象依据”，再运行 `python3 scripts/source-variants/analyze.py taiji --chart chart.json --taiji-path original.upper --evidence '所问对象取本卦上经卦'`。不能在看完结果后换太极点。程序只列相对关系，不改变底层本互变与默认体用。

1. **强弱。** 先列本互变六个经卦对太极点的同气、生扶与克泄耗，再列节令月支对应的旺、相、休、囚、死。卦内关系和月令是两组证据；不能仅按数量或月令自动判从旺、从弱。
2. **空亡。** 用日干支求旬空。某卦是否真空仍需核其纳支、动静和强弱；见空不等于事无。
3. **墓库。** 金丑、木未、火戌、水土辰是墓支候选；未定旺衰时不能自动区分入墓与入库。
4. **应期。** 只有已确认强而不从、弱而不从及所问现实阶段，才使用相应克制或生助的条件式线索。纳支、单一月令或单个卦数不能换算为事项完成日期。

程序提供可检查的候选和前提，不自动判成败、从格、喜忌或唯一应期。若前提不足，说明缺口并停止于条件判断。
