# 数码结构与候选

此方法用于明确研究 11 位号码或末四位数位，不是普通“报两个数起卦”。输入 11 位时分为 `3+4+4` 三段，并把后八位两两分为元、会、运、世四格；只给末四位就只分析末四位，不补造前七位。不同数卦映射表各自标注，不把同一数字在不同表的经卦拼成一盘。

末四位按“夹、靠、翻、转”列出多个数位组合；还可列三合支对应的数字候选和三行逐位变数。运行 `python3 scripts/source-variants/analyze.py number --digits 1703` 查看。号码可对应多个年龄或流年；没有任意号码通用的唯一选行、择岁数公式。只能在事前已定的起用时间、年龄范围和事项条件下筛选，并说明是条件筛选后的候选。

数码结构与把末四位分组起一张六画卦是不同方法；两者同源于同一号码，不能当作独立复验。涉及医疗、事故、刑事或理财时，只讨论方法输出，不把数位象意当成现实事实。
