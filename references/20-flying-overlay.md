# 飞宫五行与日月标签

仅在用户明确选择此方法且起数口径已固定时使用。可选钟点、钟点拆位、末四位分组或已核姓名笔画；每一种起数方式须在排盘前确定，不能算完后择卦。具体分组见 [起卦方法](01-casting-methods.md)。

先排出固定盘，再运行 `python3 scripts/source-variants/analyze.py flying --chart chart.json`。程序把本、互、变六个经卦相对体卦的五行关系列为飞宫标签，并列实际节令月支、日支与体卦的关系；缺日干支时不填造。

同一张盘加标签不是独立复验。日月关系、卦组同气与体用过程须合参；单一“生体”或“克体”不自动判成败或应期。卦名直读只选与所问阶段有关的一两个象，不从类象表中事后挑答案。
