# 方法覆盖与执行边界

本表只列本 Skill 可以执行的动作、所需输入和停止条件，不记录资料名称、作者或页码。遇到未列出的公式，不凭模型记忆补造。

| 方法层 | 已接入的动作 | 主要限制 |
| --- | --- | --- |
| 起卦 | 公历转农历时间、已核农历时间、两数/三数、物数、声数、字数、已核笔画、丈尺/尺寸、后天物象与方位 | 起法在看盘前固定；分钟不入默认时间式，笔画和方位不可猜。见 [起卦方法](01-casting-methods.md)。 |
| 盘面 | 上下卦、动爻、本卦、互卦、变卦、体用及体互用互 | 由 [排盘程序](../scripts/meihua-engine/README.md) 计算，不临时手算。 |
| 主链 | 体用生克、本互变过程、卦气强弱和卦辞爻辞的限定使用 | 不把每一个类象当作独立吉凶票。见 [体用](02-body-use.md)、[判断原则](09-interpretive-principles.md)。 |
| 现场 | 外应真伪、三要十应、人物动作、器物、方向和动静向背 | 必须是真实同步输入；原盘旁证不重复起卦。见 [外应](03-external-omens.md)。 |
| 事项 | 十八类分类占、现代求职考试、项目、店铺、观物 | 先拆现实阶段，再判断支持到哪一步。见 [分类占](05-topic-reading.md)、[观物](11-object-reading.md)。 |
| 时间 | 成卦数、卦气、动静、来去向背与现实流程合参 | 没有阶段或尺度前提时只报触发线索，不报完成日期。见 [应期](04-timing.md)。 |

以下可选方法独立运行，不能静默并入默认体用主链：[策轨与古音](18-cegui-phonetic.md)、[太极点卦组](19-taiji-overlay.md)、[飞宫日月](20-flying-overlay.md)、[数码结构](21-number-profile.md)。只有输入和判据都满足时才执行相应步骤；不完整的判断保持未定。

本仓库不处理独立拆字测字、六爻纳甲、八字或跨体系自动合盘。
