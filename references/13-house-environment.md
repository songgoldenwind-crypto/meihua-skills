# 屋宅、店铺与环境观察

本章把家宅、屋舍、店铺与现场环境分为可核实的观察项。传统宅象只用于象意分析；结构安全、消防、卫生、用电、排水和经营决策必须依据现场检查与专业意见。

## 先分所问层级

- **家宅：** 人与家庭运行，体为求测主体，用为居住关系。
- **屋舍：** 建筑或场地本身，体为使用者，用为房屋条件。
- **店铺：** 场地、客流、设备、合同与经营分开判断。
- **环境外应：** 起卦现场突然发生的门窗、水流、声响、破损等，只作同步验证。

房屋一直存在、没有异常变化，也没有明确问题时，不仅因“看到房子”就起卦。可在签约、开工、搬入、开业、故障、改造或突发异常等可复核时点起卦。

## 体用关系

| 关系 | 家宅或屋舍中的基本含义 |
| --- | --- |
| 用生体 | 场地支持居住者或经营者，资源较易回到主体 |
| 体克用 | 主体能控制、修整或取得场地，但要核实成本 |
| 比和 | 人与场地匹配、运行阻力较少 |
| 体生用 | 持续投入、维护或资金被场地消耗 |
| 用克体 | 场地条件压制主体，可能是成本、故障、距离或制度限制 |

互卦查看施工、审批、搬运、客流和家庭协调等中间环节；变卦看启用后的状态。不能由一处生克直接断“旺宅”或“凶宅”。

## 八卦环境定位

- 乾：高处、大型建筑、行政办公、金属结构、西北。
- 兑：开口、破损、餐饮、沟通区、低洼水边、西。
- 离：采光、招牌、屏幕、电力、厨房、消防、南。
- 震：道路、入口启动、车辆、机器、树木、东。
- 巽：通风、管线、长廊、物流、人流进入、东南。
- 坎：给排水、暗处、低处、风险通道、北。
- 艮：墙体、门槛、边界、仓储、停止点、东北。
- 坤：地面、承重、后勤、仓库、田地、西南。

一个现实问题只选相关类别。例如漏水先看坎与管线，招牌故障先看离；不因同一房屋同时具备八类设施而全部展开。

## 传统环境征象的现代化读取

传统环境象列出门墙残缺、排水向门、屋瓦坠落、异常烟火、动物入屋、树木遮压、器物破碎等大量吉凶词。执行时把它们还原为可检查条件：

- 门墙、台阶、屋瓦、器皿破损：维护缺口、通行风险或形象受损。
- 水流直冲门口、积水、沟槽异常：排水、潮湿、动线或财物保管问题。
- 长期冷落、异味、动物粪污：卫生、空置、通风或管理不足。
- 门窗明亮、整洁、通风顺畅：使用条件较好，但仍不代表经营必然成功。
- 树木压墙、根系侵入、枯枝坠落：遮光、结构、排水和坠物风险。
- 白天异常灯火、线路发热、灶火失控：优先做消防和电气检查，不作灾祸预言。
- 动物突然争斗、鸣叫或闯入：先查现实原因；只有与起念同步且异常时才作低权重外应。

不得把传统歌诀中的疾病、死亡、家人灾祸或伦理指控作为现实结论。

## 店铺与开业

按五个阶段判断：

1. 场地和合同能否取得。
2. 装修、证照、设备和供应能否齐备。
3. 开业节点能否启动。
4. 客流、交付和现金回流能否运行。
5. 成本与复购能否维持。

震巽可表示启动、通道、传播与客流；离可表示招牌、营销、文书和电力；兑可表示销售、口碑、餐饮和破损；坎可表示现金流、物流风险和排水；坤艮可表示场地、承载、库存和停滞；乾可表示规则、房东、管理或设备。类象必须落在上述阶段，不能只凭“生体”断盈利。

## 坐端与方位

现场姿态法观察求测人当时的坐、立、行、卧、朝向和身边器物。现代使用只取两类信息：

- 动静用于快慢：走动偏快，站立居中，坐卧偏迟。
- 所在方位用于方应：换算成经卦后与体比较生克。

求测人临时换座、刻意摆物或知道规则后制造的动作，不作为自然外应。方位不用于替代选址数据、租金、客流统计、消防和规划要求。
