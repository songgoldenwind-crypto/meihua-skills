# 方法分流与冲突处理

默认先按 [起卦方法](01-casting-methods.md) 固定一张梅花盘，再按 [判断原则](09-interpretive-principles.md) 和所问事项解读。以下方法只有用户明确选择、必要输入齐全时才启用。

| 输入或明确要求 | 使用方法 | 不混用的部分 |
| --- | --- | --- |
| 农历年月日时、两三数、真实物数/声数/字数 | 默认时间或数卦 | 不看完结果后更换取数口径。 |
| 两次抓米计数和时支 | 先下后上、两次数与时支合取动爻 | 不覆盖普通两数法。 |
| 钟点拆位、电话末四位或姓名两组已核笔画 | 预先选定的数字变体 | 不与默认农历时间式互换。 |
| 确认的六画卦与动爻，要求策轨乘加 | [策轨计算](18-cegui-phonetic.md) | 辅助器不替用户补出此法所需的原始起卦步骤。 |
| 已核古反切、声卦和音卦，要求横合挂一 | [古音组合](18-cegui-phonetic.md) | 现代普通话不能代替古音；缺声/音卦则停。 |
| 预先固定太极点，要求卦组、月令五态和条件应期 | [太极点法](19-taiji-overlay.md) | 不以纳支单项给唯一日期，不替默认体用换主体。 |
| 明确要求飞宫五行及日月标签 | [飞宫日月法](20-flying-overlay.md) | 先固定该法起数口径，再叠加其标签；不临时改盘。 |
| 手机号或末四位的数字结构 | [数码结构法](21-number-profile.md) | 与末四位数字起一张梅花卦是不同任务，不说成独立复验。 |

若多种方法得到不同判断，先核输入是否相同、问题阶段是否相同、每种方法是否满足自身条件。不能把不同公式的有利片段拼成单一结论；同一张底盘的多个标签也不是多次独立验证。
