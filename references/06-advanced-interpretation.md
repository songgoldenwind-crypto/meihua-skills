# 体互用互、卦气与十应

本章整理梅花主法中的体用互变、卦气旺衰、真假生克、动静向背与十应的执行口径。它们用于给主链排序，不能各自生成一条互不约束的吉凶断语。

## 体互与用互

动爻在下卦时，下卦为用、上卦为体；动爻在上卦时，上卦为用、下卦为体。互卦仍分上下：与体处于同一位置的经卦为**体互**，与用处于同一位置的经卦为**用互**。

判断顺序固定为：

1. 本卦体用说明当前主体与事项的直接关系。
2. 体互说明主体在中间阶段的内在条件、承受或变化。
3. 用互说明事项、对方或外部条件在中间阶段怎样展开。
4. 变卦说明动爻变化后的末段趋势。

程序输出的 `body_use.body_position`、`use_position`、`body_mutual` 和 `use_mutual` 是唯一位置依据。体互、用互只用于同一事项的过程，不各讲一个新故事。体互与用互方向相反时，指出是主体条件与外部进程不一致，并说明现实中需要核实哪一环。

程序保留的互卦重卦名称只用于卦形审计。实际过程判断优先使用体互、用互两个经卦，不从互卦名称另讲一套卦名故事。

## 卦气旺衰

按月支归季使用以下基础表：

| 月支 | 旺 | 衰 |
| --- | --- | --- |
| 寅、卯 | 木（震、巽） | 土（坤、艮） |
| 巳、午 | 火（离） | 金（乾、兑） |
| 申、酉 | 金（乾、兑） | 木（震、巽） |
| 亥、子 | 水（坎） | 火（离） |
| 辰、戌、丑、未 | 土（坤、艮） | 水（坎） |

旺衰只调整已有关系的承受力和实现力：体旺较能承受克泄，体衰遇克则压力加重；生体之卦旺，支持较实；克体之卦旺，阻力较实。旺衰不能把不存在的作用变出来，也不能用“得令”直接跳到录用、到账、复合或痊愈。

有实际占问时间时，以程序返回的 `seasonal_qi` 为准。非时间起卦也应用 `--context-datetime` 记录事件时刻，使卦气有可复核的历法依据。没有月支时不凭当前系统日期补旺衰。

## 党多与关系优先级

体、体互或其他同五行卦重复，可视为主体一侧条件较多；用、用互或变卦同类重复，可视为事项一侧力量集中。只计算与主链有关的重复，不把所有经卦机械计分。

主链优先级为：本卦直接体用关系最高，体互和用互解释中间过程，变卦解释末段；真实且同步的外应用于确认、削弱或限定。卦名、卦辞、爻辞和物类必须服从这条主链，只有题目本身要求天气、物品类别等不以体用为主的事项时才另定规则。

### 制约与通关

重复类象不是简单加分，还要看它是否被别的五行制约：

- 乾兑金集中，可制震巽木；在天时题中，木象受制时不机械断雷风。
- 坤艮土集中，可制坎水；坎虽出现，也可能表示水受阻、量少或尚未形成。
- 坎水集中，可制离火；离虽出现，也可能表示光热受抑或先明后暗。
- 生体之卦被另一旺卦所克，支持打折；克体之卦又被制，压力可缓解。

只沿实际生克链判断一次，不把“克克者为生”等关系无限追溯。若两条链势均力敌，输出条件分支而不是人为计分。

## 真假生克与轻重

外应五行必须区分真实作用与形色类象：

- 炉火、烈焰等真实火源可以实际克金；红色、尖形或火的图案只有离象，作用较轻。
- 河水、雨水等真实水体可以实际克火、生木；黑色、潮湿或水纹只有坎象，作用较轻。
- 刀斧、锯刃等能切木的金器，克木较实；首饰、薄片或小金属物作用较轻。
- 柴薪可直接生火，未砍伐的树木与火的关系较迟；土壤可生金，瓦器只有土象而不等同于真实生金过程。

大小、数量、距离、是否接触主体和真实功能共同决定轻重。颜色、谐音、装饰图案不得压过真实动作与作用。

## 动静与向背

- 动而来、生体：支持正在接近，通常较快。
- 动而去、生体：支持可能已经过去或正在减弱。
- 动而来、克体：压力正在接近，通常较快。
- 动而去、克体：压力正在离开或已经释放。
- 静物没有异常变化时只作环境，不自动取得决定权；被人拿来、移动、开启、破损或突然发声后，才按当时真实动作判断。

求测者当时行走、站立、坐下或卧息只能辅助快慢：行走偏快，坐卧偏迟，站立居中。它不能单独决定具体天数。

## 十应的分层记录

| 应 | 读取对象 | 作用 |
| --- | --- | --- |
| 正应 | 本卦体用 | 当前直接关系 |
| 互应 | 体互、用互 | 中间过程 |
| 变应 | 变卦 | 末段趋势 |
| 方应 | 求测人或来物所在方位 | 生克体及远近方向 |
| 日应 | 占问当日与月令卦气 | 强弱与触发条件 |
| 刻应 | 起卦当刻的所闻所见 | 即时旁证 |
| 外应 | 偶见的真实外物 | 真假、轻重、向背和动静 |
| 天时应 | 晴、雨、风、雷等 | 环境是否呼应体用 |
| 地理应 | 水边、火场、林木、金属、土石等实际场所 | 环境五行与体的关系 |
| 人事应 | 当场真实发生的人物、言语和行动 | 确认、削弱或限定主链 |

同一个现象只能归入最直接的一类，不在方应、外应和人事应中重复加权。没有真实输入的应留空，不由模型补齐“十项”。

### 日应、时令应与方应

日应查看占问当日地支所属五行和体卦关系，月令决定更稳定的季节背景；日应不覆盖月令，只可表示某一天的触发或短暂增强。没有可靠当地日期时不补日应。

方应既看求测人或来物处在何方，也看作用从何方而来：本卦同方或生扶方可增强其象，受该方五行克制则减弱。例如坎水之物从北方来，水象较实；从土旺方位来，只可视为水受约束的候选。方位必须是实际相对方位，不把地图绝对方位、视线方向和来路方向混为一谈。

### 十应不是十票

正、互、变来自同一卦，月日来自同一时间，刻应、外应和人事应也可能来自同一事件。合参时按来源分组：卦内结构是一组，历法强弱是一组，现场真实事件是一组。最多只能说三个来源是否同向，不能宣称“七项吉、三项凶所以七成吉”。

## 合参结论

先写正应，再看互应和变应能把事项推进到哪一阶段；日应用于强弱，现场诸应用于验证。多数条目来自同一现象或同一卦形时不按票数计算。出现矛盾时保留最强反证，并降低结论层级或时间精度。
