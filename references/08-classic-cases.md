# 经典案例的校验用法

以下示例用于检验方法步骤。它们用于校验“怎样从输入走到判断”，不把古例结果制成固定事件模板，也不以古例中的极端结果推断现实伤亡。

| 案例 | 起法与结构 | 可复用的方法 | 不可复用的结论 |
| --- | --- | --- | --- |
| 花卉时间例一 | 年月日时得泽火革，初爻动；体受克，互中再见相关克象，变卦转生体 | 本卦定压力，体互/用互分中段，变卦看末段缓解；异常事件是起卦触发 | 见兑、巽便固定断女子伤股 |
| 花卉时间例二 | 年月日时得天风姤，五爻动；用与互卦多见金克木 | 同类克体信息集中且无生扶时，阻力较实；再用现场对象限定含义 | 见乾便必断马匹践花、午时必发生 |
| 夜间借物例 | 敲门一声、五声起天风姤，结合冬夜借物的现实用途辨物 | 数与卦先给候选，现实时间和用途负责排除不合场景的候选 | 乾巽组合永远代表斧头 |
| 今日动静 | 以文字声调或字数成卦，再结合互卦与物类判断当天事项 | 起法必须先固定；类象只围绕当天问题收束 | 无坎便一律断无酒，见坤便固定有饭局 |
| 牌额笔画例 | 以牌额笔画起卦，并结合场所性质和字形缺损 | 字占数法必须保留原字、实际笔画和场景；卦理与现实结构合看 | 改字可以保证改变现实祸福 |
| 老人忧色、少年喜色 | 人物类象与来方成卦，表情是已存在的现场倾向 | 外应可以先限定问题方向，再由体用、互变和爻辞复核 | 从表情直接断具体灾祸、婚期或死亡 |
| 牛鸣、鸡鸣、枯枝坠地 | 异常声音或动作作为后天端法入口 | “不动不占”；悲喜、来方、物类和时支需先冻结，再排盘 | 同类动物或枯枝出现就复制古例结果 |
| 风觉、鸟占、听声音 | 风向、鸟数、鸣声或物声先被观察，再选择一种主特征 | 先分起卦数、物象卦和旁证；声势悲喜只限定强弱 | 鸦、鹊、颜色或叫声天然固定吉凶 |
| 笼中物、钟覆物 | 先用卦形、体用、互变猜材质形态，再由爻辞和现场限定 | 猜物须在揭晓前保存候选和反证，揭晓后统计误差 | 从结果反查所有能对应的类象，宣称全部命中 |
| 乾坤病占问答 | 同一重卦六个动爻形成不同变卦和互卦 | 动爻改变末段结构，不能只凭本卦名称断同一结果 | 复制示例中的死亡、用药或鬼神判断 |
| 观物洞玄与屋宅歌 | 观察门墙、水流、树木、器物和动物状态 | 把歌诀还原为维护、排水、卫生、动线和环境条件 | 由破碗、动物或树木直接断家人灾祸 |

## 回测模板

每个案例或真实旧卦按同一格式复盘：

1. 当时实际问题、触发和时间是什么。
2. 起卦前固定了哪些数字、物象、方位或声音。
3. 程序得到的本卦、动爻、体用、体互、用互和变卦是什么。
4. 哪一条生克链决定了能推进到的现实阶段。
5. 外应是起卦入口还是旁证，有没有重复使用。
6. 原判断中哪些信息是事前可得，哪些可能是事后附会。
7. 现实结果验证了哪个阶段；未验证部分删除，不通过改单位或改象维持原断。

用案例校正规则时，只吸收能够跨案例复现的步骤。单次命中的具体物品、身份、伤处和日期不升级为通用口诀。
