# 十八类占问与现代事项

## 共用方法

先确定体代表谁、用代表什么，再把问题拆成必经阶段。本互变最多支持到哪一层，就断到哪一层。下列关系是起点，不是机械吉凶表：

- 用生体：事项、对方或环境向主体提供支持。
- 体克用：主体能够取得、控制或处理事项，但要检查体是否有力和成本。
- 比和：同类、协调或阻力较少，仍要看是否有实际行动。
- 体生用：主体投入、消耗或向外提供。
- 用克体：事项或环境压制主体，检查互变是否缓解。

本章覆盖十八类传统占问，并把现代工作、考试和项目归入相应入口。传统规则只表达体系内趋势；医疗、法律、气象、建筑和财务事实必须另行核实。

## 一、天时

天时占不以体用为主，综合本卦、互卦和变卦：离多偏晴热，坎多偏雨水，巽偏风，震偏雷动，坤偏阴晦，乾偏晴明，艮偏云止或天气转止，兑偏阴泽。还须结合季节：冬见震不直接断雷，优先理解为风撼或突变；夏见乾兑不直接断霜雪。

先定地点与时间窗，再写天气过程。重坎重离、既济未济等水火并见可表示晴雨转换；艮的“止”只有在前段已有雨、风或云时才表示转止。术数不能替代气象预警。

## 二、人事

人事是一般事项总入口。体为求测主体，用为对方、任务或现实环境；用生体、体克用或比和较易推进，体生用常见投入，用克体常见压力。互卦看沟通与办理，变卦看结果条件。没有生克时，以本卦动作、重卦语义和现实流程为主。

## 三、家宅

体为居住主体，用为家庭运行。体克用可表示能管理家务或环境，用生体可表示家庭支持，体生用表示持续投入，用克体表示家庭条件压身，比和表示较协调。需分别核实关系、费用、维护和空间，不把一个关系词直接断成家运吉凶。环境细则见 [13-house-environment.md](13-house-environment.md)。

## 四、屋舍

体为使用者，用为房屋或场地。体克用表示可控制、修整或取得场地；用生体表示场地支持；体生用表示装修、租金或维护消耗；用克体表示距离、结构、合同或设备等条件压制；比和表示适配。结构安全和产权以检查、合同与登记为准。

## 五、婚姻与关系

体为求测一方，用为关系、对象或对方家庭。用生体可见对方靠近或关系提供支持；体生用可见单方投入；体克用可见主动推进但也可能控制过多；用克体可见压力或不匹配；比和可见协调。

按“接触 → 双向互动 → 条件一致 → 关系确认 → 稳定履行”判断。卦象不能确认爱意、出轨、怀孕、婚期或他人隐私。旧式条目以八卦猜外貌、品性和性别的条目只作历史材料，不用于现实识人。

## 六、生产与新增成果

传统生产占涉及母婴与性别，现代执行只保留抽象结构，用于项目交付、作品发布、产品上线等“孕育—产出”问题：体为承载方，用为待产出成果；体用俱有力且相生表示条件较顺，体克用表示成果受主体控制但可能压缩，用克体表示成果压力反噬主体。

不判断胎儿性别、分娩风险、母婴生死或日期。真实孕产问题必须依医疗评估。

## 七、饮食

体为用餐者，用为饮食或邀约。用生体可表示食物与条件到位，体生用表示准备、请客或付出，体克用表示选择和控制，用克体表示不适配或未能享用，比和表示较顺。坎可取酒水汤液，兑可取入口与餐谈，离取煎烤热食，坤取主食，震巽取蔬果。完整观物口径见 [11-object-reading.md](11-object-reading.md)。

## 八、求谋

体为谋事者，用为计划。体克用表示计划可控但可能需要时间；用生体表示资源主动到位；体生用表示投入多、回报待查；用克体表示条件反压；比和表示配合。按“想法 → 资源 → 行动 → 审批/协作 → 完成”拆阶段，不用一句“可成”越过中间环节。

## 九、求名、考试与求职

体为本人，用为职位、考试、资格或名誉。用生体可见机会或规则支持，体克用可见能取得但需主动作答和竞争，比和表示匹配，体生用表示准备投入，用克体表示门槛或考核压制。

求职与考试按“资格 → 联系/准备 → 面试或考试 → 决定/文书 → 到岗或录取”判断。乾可限定规则和负责人，离限定文书与展示，震巽限定行动沟通，坎限定流程风险，艮限定停顿；这些都服从体用主链。

同时有多家公司或考试时，没有分别立极依据就只判断哪一阶段推进，不指定某一家。得到机会与得到理想条件分开：薪资、距离、职责和发展目标以用户实际标准核对。

## 十、求财

体为求财者，用为财源。体克用可表示取得或控制财，用生体表示资金或资源回流，体生用表示成本和投入，用克体表示损耗或债务压力，比和表示流转较顺。

按“来源 → 交易/履约 → 到账 → 留存”判断。见财象不等于已经到账；变卦继续耗体时，要区分收入与最终留存。市场走势与本人能否执行、获利分开，不给投资指令。

## 十一、交易

体为己方，用为交易、货物或对方条件。用生体与比和较易达成，体克用表示掌控价格或货物但可能延迟，体生用表示让利或成本增加，用克体表示对方条件压制。互卦看谈判、验收与物流，变卦看签约、交割和售后。

合同、付款、产权和质量以书面文件和检验为准。

## 十二、出行

体为出行者，用为路线和旅程。体克用表示路线可控，用生体可见帮助或资源，体生用见耗费，用克体见风险，比和见顺行。乾震多可见发动，坤艮多可见停留，巽可见进入或风行，离可见陆路和照明，坎可见水路或险阻，兑可见口舌和换乘。

按“准备 → 启程 → 途中 → 到达 → 返程”判断，不能由出行有利直接保证交通安全。

## 十三、行人和来人

体为等待方，用为行人或消息。用生体可表示对方接近或消息来到，比和表示联系顺畅；体生用可表示等待方主动联系或对方仍在外；体克用可表示能联系但归来偏迟；用克体表示阻滞或关系压力。

震多偏移动，艮多偏停，坎偏险阻，巽偏消息传递。按“有意 → 动身 → 接近 → 到达”分层；只支持消息时不能断人已经到达。

## 十四、谒见与会面

体为求见者，用为所见之人或门槛。体克用表示有办法接触但可能需主动争取，用生体表示对方愿意接纳，比和表示互动较顺，体生用表示付出但收益待查，用克体表示难见或见后受压。互卦重点看预约、引荐、材料和时间协调。

## 十五、失物

体为失主，用为失物。用生体或比和可表示物仍与主体有连接，体克用可表示可控制搜索范围但取得较迟；体生用表示物向外散失，用克体表示难取或受阻。

先判断“仍在可控范围 → 有位置线索 → 可以发现 → 能够取回”。变卦方位可安排搜索优先级：乾西北与高处/金属旁，坤西南与地面/仓储，震东与道路/木器，巽东南与缝隙/长物，坎北与水边/低处，离南与光电/文书旁，艮东北与门槛/土石，兑西与开口/破损处。方位不保证物品在那里。

涉及盗窃只建议查监控、记录和报警，不以卦象指认他人。

## 十六、疾病与健康

传统口径以体为病人、用为症状，体旺受生偏有承受力，体衰受克偏压力重；互变可表示过程中的缓解或反复。现代输出只能写成象意层面的“支持、耗损、阻滞和缓解条件”。

不按八卦身体部位诊断病名，不依据卦象决定冷热药、停药、手术、生死或康复日期。出现症状应按紧急程度就医。

## 十七、官讼与法律争议

体为己方，用为争议、对方或程序。体克用可表示己方能掌控论点，用生体可表示证据或程序支持，比和可见和解空间，体生用表示成本和让步，用克体表示程序、对方或责任压力。

按“事实与证据 → 沟通 → 立案/程序 → 裁判或和解 → 执行”判断。卦象不确定事实真伪、责任归属或诉讼结果，法律行动以律师与正式文件为准。

## 十八、坟墓、土地与长期安置

传统坟墓占以体为相关主体、用为地形和安置条件。现代执行只用于土地、墓园选择、长期安置和纪念空间的象意比较：坤偏平地，艮偏山石，巽震偏林木，坎偏水路，离偏向阳与人烟，乾偏高地，兑偏低洼或缺口。

用生体、体克用或比和可表示适配，体生用表示维护投入，用克体表示地形、手续或费用压力。土地权属、地质、排水、法规和祭葬要求必须现场核实。

## 多次起卦与多对象

多卦只在问题进入新阶段、输入纠错或真实新事件触发时比较。先按同一现实阶段对齐，例如只把“联系”与“联系”、“条件确认”与“条件确认”相互增强。一个卦支持消息、另一个支持完成时，不能拼成“这条消息必然完成”；须保留流程缺口。
