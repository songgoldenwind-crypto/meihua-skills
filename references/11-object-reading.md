# 观物、器物、形色与饮食

本章用于“手中是什么、物品性质、器物成败、饮食线索”等观物题。它按辨物、器物成败、数量和饮食四类任务分流。普通事项不要为了增加细节加载本章。

## 先确定任务

观物分四类，不能混断：

1. **辨物：** 推测未知物的材质、形态、功能和状态。
2. **断器物成败：** 物品能否制成、修复、使用或保存。
3. **辨数量：** 只估数量级或单复，不伪造精确件数。
4. **饮食：** 判断是否有饮食、冷热、烹调或主要类别。

若物品其实已知，直接围绕用户问的状态判断，不重复猜物。现实鉴定、食品安全和故障诊断以实物检查为准。

## 观物次序

1. 体卦定主要材质、刚柔、方圆和承受面。
2. 用卦定用途、外部作用或是否正在使用。
3. 体互、用互定内部构造、数量和加工过程。
4. 变卦和动爻定最终状态、损伤、开启或变化后的用途。
5. 月令旺衰只调整“成器、可用、数量多寡”的强弱。
6. 当场真实见闻只作克应，不能在揭晓物品后回填。

观物法有“卦多者可为体”的观物变体。只在纯辨物、用户没有主体事项且某经卦在本互变中明显重复时使用；一般事项仍遵守程序给出的体用，不能借此换体。

## 形态映射

| 可见性质 | 经卦候选 | 限制 |
| --- | --- | --- |
| 圆、坚、完整、贵重 | 乾 | 见兑可转为圆而有缺；见坎可转为沉湿 |
| 有口、缺、折、刃、开口 | 兑 | 不等于必坏，要看它是否本来就需要开口 |
| 方、厚、柔、承载、成堆 | 坤 | 见震巽可成为长形或草木制品 |
| 仰开、启动、发声、木竹 | 震 | 重点在动和声，不只看材质 |
| 长、直、绳、细、柔入 | 巽 | 见金可能被切削；见坎可能湿润或可食 |
| 外柔内刚、液体、含核、弯轮 | 坎 | 重点看流动、湿润、内藏或险陷 |
| 覆盖、边界、土石、果实、结节 | 艮 | 重点看停止、封口、硬节和门径 |
| 中空、附着、光热、纹饰、干燥 | 离 | “中空”与“文饰”须结合真实物体功能 |

同一物品可能同时具备材质、形态和动作三种象。优先当前决定用途或状态的那一项，例如空杯先取“空/口”，正在燃烧的纸先取真实火，红色金属饰品仍以金属功能为主。

## 材质、加工与成器

- 乾兑偏金石与硬器；乾偏完整坚圆，兑偏切口、缺损、加工和交换。
- 震巽偏木竹草绳；震偏发动和有声，巽偏长直、进入、编织与传播。
- 坤艮偏土石瓦器；坤偏承载、方厚和批量，艮偏结块、门槛、果实和停止。
- 坎偏水、酒、湿物、含核或流体容器。
- 离偏火、电、纸张文书、甲壳、干燥和带纹物。

生体可表示材料或条件补入，克体可表示切削、损伤或改造，体生用可表示原材被消耗，体克用可表示主体能加工或控制它。成器与否要结合题目：刀克木可能是损木，也可能正是木工加工；不能只见克就断坏。

## 动爻位置

动爻表示变化落点：初二爻偏内部、基础或下部，三四爻偏连接、接口或使用过程，五上爻偏外层、顶部、展示、远处或能移动部分。旧式判断称五、上动常见能飞动之物，只可作为弱提示；必须有震巽乾等动态类象与真实问题支持。

爻辞只在后天端法且文本已核实时使用。它可提示包裹、田野、水中、损坏等状态，但不能代替体用和实物特征。

## 数量判断

经卦数可给候选数量：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。互卦相同可提示成双或同类重复；某元素在本互变中集中且得令，可提示数量较多；衰弱受制则偏少。

这些数字首先是结构数，不保证等于实际件数。除非题目本身就是数量、输入方法明确且多个独立线索一致，否则只输出“单件/成双/少量/多件”或一个小范围。

## 季节与时宜

春木、夏火、秋金、冬水、四季土月分别使对应材质与功能更有力。季节可以判断“当令、可用、易成”，不能把不当令直接断成不存在。现实用途优先，例如冬天出现电暖器符合离火功能，不因离衰而断为假物。

## 饮食专用

饮食先看有没有，再看种类：

- 坎可表示酒、水、汤、腌汁和水产。
- 兑可表示入口、餐具、辛辣、切制和宴谈。
- 离可表示煎烤、烘焙、热食、茶火和色泽。
- 坤可表示米谷、主食、薯芋、甜味和大份承载。
- 艮可表示根茎、瓜果、坚果、块状食物和停止进食。
- 震巽可表示新鲜蔬果、木本果实、鸡禽、酸香和条状食物。
- 乾可表示圆果、坚硬或高档食物、冷食与金属器皿。

坎、兑出现不自动等于一定有酒食；若被旺土或旺火强制，可能变成少、无、干涸或不适用。体用决定谁提供、谁消耗，互卦可看席间人物或加工，变卦看最后能否入口。食品过敏、变质和安全不能由卦象判断。

## 现场揭晓后的复盘

揭晓前保存原判断，至少写出材质、形态、功能、状态四项中的两项，并给一项反证。揭晓后只标哪些命中、哪些不符；不从类象表中追加此前未写的对应项。连续积累误差，用来缩小映射，不用“万物皆可类推”解释所有失败。
